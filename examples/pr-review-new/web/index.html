使用指引

1. 另一终端启动裸 agent：python examples/pr-review-new/agent/agent.py
2. 左侧新建 PR（svc-orders 免审批直跑；svc-payments 生产仓库进审批闸门）
3. 点击 PR 行看实时直播（thought / tool_call / token 混合流）与评审结论
4. 顶栏切换角色验证权限矩阵：越权操作会被控制面真实 403 拒绝
5. admin 视角可查审计尾部与 /metrics；无 LLM key 时 agent 自动 mock 降级
